# Evaluation

Compared methods (all on the same synthetic gridded cases):

1. Each individual source (bias-corrected)
2. Equal-weight average
3. Best single source (retrospective)
4. Skill-only softmax gate
5. TreeGate / KiWi blend

Metrics: MAE, RMSE, bias, correlation, extreme precision/recall/F1,
interval coverage vs nominal, average interval width.

KiWi is not claimed to be better unless the metric table shows it.
