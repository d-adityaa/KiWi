# Dashboard guide

Run: `python scripts/run_dashboard.py` (port 8501).

Pages: Overview, Forecast Desk, Model Comparison, Trust Atlas,
Confidence & Uncertainty, Extremes & Risk, Spatial Explorer,
Lead-Time Performance, Data Health, Run History, Model Registry,
Export & Bulletin.

Every page shows the Demo/Synthetic label and the standard footer.
Language switch (EN/HI) is in the sidebar.
